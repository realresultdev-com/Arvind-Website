# Dr. Aravinth's Dental Care - Namakkal

Official responsive web application for **Dr. Aravinth's Dental Care**, located on Salem Main Road, Namakkal, Tamil Nadu.

## 🦷 Key Features
- **Bilingual Interface**: Seamless instant toggle between English and Tamil (தமிழ்).
- **Interactive Google Reviews**: Single-row continuous marquee animation with verified 5.0-star reviews and pause-on-hover.
- **Comprehensive Dental Services**: Preventive, restorative, pediatric, and orthodontic treatments with transparent details.
- **Doctor Profiles**: Detailed credentials and expertise of Dr. P. Aravinth (BDS, FICOI) and Dr. Sangavi Aravinth (BDS).
- **Online Booking**: Direct appointment scheduling via WhatsApp and Email.
- **Location & Navigation**: Embedded interactive Google Map with direct GPS directions and landmark guidance (Opposite Sanu Hotel).

## 🚀 Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Routing**: React Router v7

## 🛠️ Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
